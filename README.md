# Hoja de vida — Formato Campuslands

**Georgy Nikolas Tolosa Blanco** · Desarrollador de Software Junior en formación

Este repositorio contiene la entrega final del **Proyecto #1 — Hoja de vida formato Campuslands** (curso de Empleabilidad).

## ¿Por qué está en un repositorio?

La plataforma de Campuslands **no tenía la opción de enviar la entrega como archivo**. Solo permitía ingresar la *ruta de un repositorio* y un *hash*. Por eso el PDF está alojado en este repositorio público de GitHub.

## ¿Cómo descargar el PDF?

### Opción 1: desde la página del archivo
1. En la lista de archivos de arriba, haz clic en **`Hoja_de_vida.pdf`**.
2. GitHub abre una vista previa del PDF.
3. Arriba a la derecha de la vista previa, haz clic en el botón **Download raw file** (icono de flecha hacia abajo ⬇️).
4. El PDF se descarga en tu equipo.

### Opción 2: enlace directo
Abre este enlace y el PDF se descarga o se abre en el navegador:

[Descargar Hoja_de_vida.pdf](./Hoja_de_vida.pdf?raw=true)

### Opción 3: descargar todo el repositorio
1. En la página principal del repositorio, haz clic en el botón verde **`<> Code`**.
2. Selecciona **Download ZIP**.
3. Descomprime el ZIP y abre `Hoja_de_vida.pdf`.
